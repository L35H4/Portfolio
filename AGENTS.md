# Портфолио Алексея Корепанова

Это основная локальная копия сайта-портфолио. Сайт опубликован через GitHub Pages на `https://www.korepanov.art/`.

## Структура

- `index.html` — разметка всех разделов и кейсов.
- `assets/site.css` — визуальный стиль и адаптивная верстка.
- `assets/site.js` — навигация, галереи и интерактивные элементы.
- `assets/` — изображения и остальные ресурсы.
- `resume.pdf` — резюме для скачивания.
- `CNAME` — домен GitHub Pages. Значение должно оставаться `www.korepanov.art`.

## Правила работы

- Работай прямо в этой папке и сохраняй существующий простой стек HTML/CSS/JavaScript.
- Не выдумывай факты, метрики, исследования, отзывы или вклад автора. Используй только материалы и формулировки, подтвержденные пользователем.
- Сохраняй текущую структуру страниц, если пользователь явно не просит её изменить.
- Проверяй изменения на широком и мобильном экране. Учитывай доступность, читаемость, скорость загрузки и базовое SEO.
- Не публикуй изменения без явной просьбы пользователя. Публичный репозиторий: `https://github.com/L35H4/Portfolio.git`, ветка `main`.

## Локальный просмотр

Запусти локальный статический сервер из корня проекта и открой `http://127.0.0.1:8766/`.

Пример команды:

```powershell
python -m http.server 8766 --bind 127.0.0.1
```
